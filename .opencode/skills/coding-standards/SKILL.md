## Стек
- **Чистый JavaScript** (ванильный Node.js): без TypeScript, без транспиляции, без бандлера
- **ESM** — `"type": "module"` в package.json, `import`/`export` в `.js`
- **Zero-dependency** — только стандартная библиотека Node и `node:test`/`node:assert`
- **Без внешних LLM/API** — вся логика детерминированная и быстрая

## Структура
- `src/` — модули логики: один класс/задача = один файл
- `*.test.js` — тесты рядом с исходником (`src/foo.js` → `src/foo.test.js`)
- Запуск тестов: `node --test`

## Стиль кода
- Функции `camelCase`, файлы `kebab-case.js`
- Чистые функции в ядре: без побочных эффектов и I/O внутри классификации
- Без комментариев, если не просили
- Без `console.log` в production-коде — только через явный вывод/обработчик

## Детерминизм
- Классификация — чистая функция от входной строки: одинаковый вход → одинаковый результат
- Без `Date.now()` / `Math.random()` в решающей логике
- Пороги уверенности и словари вынесены в константы (например, `thresholds.js`), не magic numbers

## Производительность и безопасность
- Линейные проходы по строке (`O(n)`), без вложенных сканов по входам
- Регулярки без катастрофического backtracking (ReDoS): литеральные паттерны, без вложенных квантификаторов
- Без `eval` / `new Function` / `child_process` для обработки входных данных
- Ограничение длины входа на старте обработки (пустой/`null` вход → `UNCLEAR`, не throw)
